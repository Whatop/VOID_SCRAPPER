# Professor CD1 Audio Applied

교수님 공유 자료 `CD1 - Aircraft, Vechicles & Machinery.zip`에서 VOID SCRAPPER에 임시 적용할 기계/차량/전기/금속 계열 사운드만 선별해 기존 SoundEventLibrary에 연결했다.

## 적용 범위

- Player: 대쉬, 피격, 기체 파괴
- Enemy: 차징 예고, 피격, 사망, 보안 드론 생성
- Objects: 컨테이너, 잔해, 선체, 암석 피격/파괴
- Core/Boss: 코어 상호작용/활성화, 보스 등장, 레이저, 차징포, 2페이즈, 사망
- Shop Combat: 보호막 피격/파괴, 적대화
- Return: 귀환 비콘, 웜홀 진입

## 주의

이 패치는 UI/상점 UI/보상 UI 사운드는 건드리지 않는다.
무기 레이저 계열도 CD1 특성과 맞지 않아 기존 Kenney 세팅을 유지했다.

상세 매핑은 `ProfessorCD1_Audio_Applied_Mapping.csv`를 확인.
