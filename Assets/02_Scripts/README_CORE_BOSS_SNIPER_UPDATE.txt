VOID SCRAPPER - 코어/보스 인트로 + 스나이퍼 차징 수정
기준 소스: 02_Scripts(25).zip

============================================================
1. 적용된 흐름
============================================================

코어 상호작용 완료
→ 플레이어 입력/HUD 잠금
→ 카메라가 코어 위치로 이동하면서 확대
→ 코어 Activate 애니메이션 또는 기본 확대/색 변화
→ 노란색 원형 펄스 3회 확산
→ 코어 Collapse 애니메이션 또는 기본 축소 후 비주얼/콜라이더 숨김
→ 전장 전체 줌아웃
→ 레이저 관리 기체 진입 및 봉쇄벽 생성
→ 보스가 화면 밖에서 중앙으로 진입
→ BossIntroEnter / BossIntroReveal 애니메이터 트리거
→ 보스 쪽으로 다시 확대
→ 구획 관리자 등장 타이틀
→ 보스 체력바가 가로로 펼쳐지고 HP가 0부터 현재값까지 채워짐
→ 카메라 복귀
→ BossIntroReady 트리거
→ 보스 AI 및 플레이어 조작 활성화

============================================================
2. 자동 동작과 선택 연결
============================================================

필수:
- CoreObject의 Use Boss Intro Sequence = ON
- 씬에 CameraZoomController2D와 GungeonStyleCamera2D가 존재
- 씬에 BossHealthBarUI가 존재

자동 처리:
- CoreActivationPresentation이 없으면 CoreBossIntroSequence가 런타임에 자동 추가
- 코어 Animator가 없어도 기본 확대/색 변화/축소 연출 사용
- 노란 펄스 프리팹이 없어도 LineRenderer로 런타임 생성
- 보스 Animator 트리거가 없어도 기본 스케일 오버슈트 연출 사용
- 스나이퍼 차징 라인이 없어도 런타임 생성
- 차징 게이지 CanvasGroup이 없어도 런타임 추가
- CameraZoomController2D 참조가 비어 있으면 자동 탐색

============================================================
3. 코어 Animator 선택 설정
============================================================

코어 또는 코어 자식 Animator에 아래 Trigger를 만들면 사용한다.
- Activate
- Collapse

Animator가 없거나 Trigger가 없으면 기본 스크립트 연출이 대신 실행된다.

타버린 외곽 프레임을 남기고 싶은 경우:
- CoreObject에 CoreActivationPresentation을 직접 추가
- Visual Root에는 중심 에너지 파츠만 연결
- Renderers To Hide / Colliders To Disable에도 사라질 파츠만 연결

모두 비워두면 코어 전체 비주얼과 콜라이더가 사라진다.

============================================================
4. 보스 Animator 선택 설정
============================================================

구획 관리자 Animator Controller에 아래 Trigger를 추가하면 인트로에서 호출된다.
- BossIntroEnter  : 화면 밖에서 진입하기 시작할 때
- BossIntroReveal : 중앙 도착 후 보스 등장 강조 시점
- BossIntroReady  : 체력바 표시 후 전투 준비 완료 시점

Trigger가 없어도 오류 없이 기본 스케일 등장 연출로 진행된다.

============================================================
5. BossHealthBarUI 설정
============================================================

권장 연결:
- Root Object: 보스 체력바 패널
- Canvas Group: 패널 CanvasGroup
- Reveal Root: 좌우로 펼쳐질 프레임/패널 RectTransform
- HP Slider: 보스 HP Slider
- Fill Image: HP Fill Image
- Boss Name Text / HP Text 연결

Reveal Root를 비우면 Root Object의 RectTransform을 사용한다.
가운데에서 양쪽으로 펼치려면 Pivot X = 0.5,
왼쪽에서 오른쪽으로 펼치려면 Pivot X = 0으로 둔다.

BossHealthBarUI가 붙은 GameObject 자체는 씬에서 활성 상태로 두어야 한다.
숨김은 코드가 CanvasGroup으로 처리한다.

============================================================
6. 보스 등장 타이틀
============================================================

EventTitleDirector에 BossEncounter 타입이 추가되었다.
별도 프리팹 Override를 연결하지 않으면 기존 Default Title Prefab을 사용한다.

기본 문구:
- 구획 관리자
- SECTOR ADMINISTRATOR

CoreBossIntroSequence에서 문구, 줌, 대기 시간을 수정할 수 있다.

============================================================
7. 스나이퍼 수정 내용
============================================================

- 좌클릭 유지 중 ChargeRatio 증가
- 좌클릭 해제 프레임을 놓쳐도 Held가 false가 되면 발사
- 탄환 생성 실패 시 명확한 Console 오류 출력
- 차징 중 런타임 조준선 표시
- 차징량에 따라 조준선 색/두께 변화
- 완충 시 조준선 노란색 펄스
- CameraZoomController2D 자동 탐색
- 차징 루프 피치와 볼륨이 ChargeRatio에 따라 상승
- sniper_charge_loop 이벤트가 없으면 sniper_charge_start를 임시 루프로 사용
- 발사/취소/비활성화 시 차징 루프와 조준선을 확실히 종료

스나이퍼 기본 규칙은 유지:
- 이동 입력이 있으면 차징 취소
- 좌클릭을 놓는 순간 현재 차징량으로 발사

============================================================
8. 차징 게이지 설정
============================================================

PlayerWorldChargeGaugeUI:
- Fill Image 직접 연결 권장
- 연결하지 않으면 이름에 "Fill"이 포함된 Image를 우선 탐색
- CanvasGroup이 없으면 자동 추가
- Hide On Start를 켜도 GameObject 자체를 끄지 않고 Alpha 0으로 숨김
- Fill Image는 자동으로 Image Type = Filled로 설정

권장 계층:
Player
└─ WorldChargeGauge
   ├─ PlayerWorldChargeGaugeUI
   ├─ CanvasGroup (없어도 자동 추가)
   └─ Fill (Image)

============================================================
9. 스나이퍼 오디오 이벤트
============================================================

권장 AudioEventDatabase 항목:
- sniper_charge_start
- sniper_charge_loop
- sniper_charge_cancel
- sniper_fire

sniper_charge_loop에는 가능하면 시작/끝이 자연스럽게 이어지는 루프 클립을 넣는다.
루프 이벤트가 없으면 시작음을 임시 반복하지만, 최종 오디오 품질은 전용 루프 클립이 더 좋다.

============================================================
10. HUD Raycast 수정
============================================================

PlayerWeaponController는 이제 실제 상호작용 UI만 사격을 막는다.

사격 차단:
- Button, Toggle, Slider 등 Selectable
- 클릭/드래그/스크롤 이벤트를 받는 UI

사격을 차단하지 않음:
- 장식용 HUD 배경
- 체력바 프레임
- 일반 Image/Text

그래도 특정 HUD에서 차징이 취소되면 해당 오브젝트의 Raycast Target과
부모 ScrollRect/Button 여부를 확인한다.

============================================================
11. 플레이 테스트 체크리스트
============================================================

코어/보스:
1. 코어 E 홀드 완료 후 카메라가 코어로 이동하는가
2. 코어가 커지거나 Activate 애니메이션이 재생되는가
3. 노란 원형 펄스가 3회 퍼지는가
4. 코어가 축소/붕괴하고 사라지는가
5. 전장 줌아웃과 관리 기체 진입이 보이는가
6. 보스가 화면 밖에서 중앙으로 들어오는가
7. 보스 타이틀이 표시되는가
8. 타이틀 뒤 체력바가 가로로 펼쳐지고 HP가 채워지는가
9. 카메라 복귀 후 보스가 공격을 시작하는가

스나이퍼:
1. HUD가 아닌 월드 영역에서 좌클릭 유지
2. 플레이어 위 차징 게이지가 증가하는가
3. 조준선이 청록색에서 노란색으로 변하는가
4. 차징음의 피치/볼륨이 점점 높아지는가
5. 좌클릭 해제 시 실제 탄환이 생성되는가
6. WASD 입력 시 차징이 취소되는가
7. Console에 스나이퍼 탄환 생성 실패 오류가 없는가
